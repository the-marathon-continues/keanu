# `keanu tui`

Open the terminal UI connected to the Gateway.

Related:

- TUI guide: [TUI](/web/tui)

## Examples

```bash
keanu tui
keanu tui --url ws://127.0.0.1:18789 --token <token>
keanu tui --session main --deliver
```
